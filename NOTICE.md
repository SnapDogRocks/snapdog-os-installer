# Asset provenance

The SnapDog SD-card application icon, Raspberry Pi illustrations, SnapDog logo, and DMG background
were imported from the former `SnapDogRocks/snapdog-etcher` repository in bootstrap commit
`f49f0fb9f78da3b7f5aae61f8b2f0b7931508a85` for the dedicated Rust implementation. That source
repository is no longer available through the GitHub API. The assets are maintained here so builds
do not depend on another checkout.

The repository history records `metaneutrons` as the importing contributor. It does not contain a
separate upstream asset-license file or creator ledger. Consequently, this notice documents the
recoverable chain of custody but must not be read as permission to reuse the artwork independently
of this application; the asset copyright holder must confirm any such reuse.

`vendor/wayland-scanner` contains the MIT-licensed `wayland-scanner` 0.31.10 release source. Its
manifest carries the upstream `quick-xml` 0.41 security dependency update while preserving the
released scanner API required by the current Linux GUI stack. The original license is included in
that directory.
