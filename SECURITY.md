# Security policy

## Supported versions

Only the latest published SnapDog OS Installer release receives security fixes.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting for this repository. Include the affected platform and version,
reproduction details, expected impact, and any suggested mitigation.

Do not test destructive paths against media containing valuable data or against devices
you do not own or have permission to use.
